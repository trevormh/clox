This is my implementation of the clox interpeter from the book [Crafting Interpreters](https://craftinginterpreters.com/)

# Branches

branch `main` is the code with all comments stripped out

branch `main-with-comments` includes all of my notes that I took while working through the book.

# Using
A makefile is included with some basic commands

`make compile` - compile the source code

`make run` - run the Lox interpreter as a REPL

`make runfile <path/to/file>` - run a Lox program from a file
